# 🌊 TripWave – Travel Website

TripWave is a modern, responsive **travel website** built using **HTML and CSS**, designed to showcase beautiful destinations and travel packages with a clean and user-friendly interface.
Interactive functionality using **JavaScript is planned and coming soon** 🚀

---

## ✨ Key Features

* 🧭 Modern travel-themed UI design
* 📱 Fully responsive across all devices
* 🖼️ Destination & package cards layout
* 🎨 Clean, well-structured CSS
* ♿ SEO & accessibility-friendly HTML5
* ⚡ Optimized images and performance-focused structure

---

## 🛠️ Technologies Used

* **HTML5** – Semantic and accessible markup
* **CSS3** – Flexbox, Grid & responsive layouts
* **JavaScript** – *Coming soon* 🔜

## 🚀 Getting Started

Follow these steps to run TripWave locally:

1. **Clone the repository**

   ```bash
   git clone https://github.com/CodeWithPurnendra/TripWave.git
   ```

2. **Navigate to the project folder**

   ```bash
   cd TripWave
   ```

3. **Open `index.html` in your browser**
